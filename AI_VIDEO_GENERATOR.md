# 🎬 AI Video Generator — Technical Documentation

This document covers every file, function, prompt, and data flow involved in the **AI Video Generation** system inside FlexiStudy Web.

---

## 📍 Overview

The AI Video Generator takes a **topic string** as input and automatically produces:
- A **60-second narration script** (spoken via browser TTS)
- **6 visual slides / scenes** synced to the script
- **3 MCQ quiz questions** to test understanding
- **Study notes** (summary, key points, fun fact)

Everything is generated by the **Groq API** using the `llama-3.3-70b-versatile` model.

## 🔄 End-to-End Flow

```
1. User visits /practice
2. TopicSelector displayed — user picks a subject topic or types custom topic
3. Router pushes to /practice/video/[topic]
4. Page calls POST /api/practice/video/compile with { topic }
5. API fires 4 Groq calls:
   └─ [1] Script generation (sequential)
   └─ [2] Scene generation  ─┐
   └─ [3] MCQ generation     ├─ parallel (Promise.all)
   └─ [4] Notes generation   ─┘
6. API returns VideoLesson JSON
7. InteractiveVideoPlayer renders scenes + narrates script via speechSynthesis
8. After video → /practice/video/[topic]/mcq
9. After quiz → /practice/video/[topic]/results
```

### `src/app/api/practice/video/compile/route.ts`
**Purpose:** Master AI orchestration API route.

**Method:** `POST`  
**Body:** `{ topic: string }`  
**Returns:** `VideoLesson` JSON

#### Step 1 — Script Generation (sequential, runs first)
```
Model:       llama-3.3-70b-versatile
Temperature: 0.7
Max tokens:  500
Structure:   intro (10s) → concept 1 (15s) → concept 2 (15s) → example (10s) → summary (10s)
Output:      Plain text string (no markdown)
```

#### Step 2 — Scene Generation (parallel)
```
Model:           llama-3.3-70b-versatile
Temperature:     0.3   ← low for strict structure
Max tokens:      1500
Response format: json_object (strict JSON)
Output:          { scenes: SceneData[] }  — exactly 6 scenes summing to 60,000ms
```

Scene type selection guidance given in the prompt:
- `TextScene` — intro, definitions, summary
- `ComparisonScene` — two concepts side by side
- `CodeScene` — code, math formulas, equations
- `TerminalScene` — CLI output, timelines, raw events

#### Step 3 — MCQ Generation (parallel)
```
Model:           llama-3.3-70b-versatile
Temperature:     0.4
Max tokens:      800
Response format: json_object
Output:          { mcqs: MCQ[] }  — 3 questions
```

MCQ schema per item:
```json
{
  "question": "string",
  "options": ["A", "B", "C", "D"],
  "correctAnswer": 0,
  "explanation": "string"
}
```

#### Step 4 — Notes Generation (parallel)
```
Model:           llama-3.3-70b-versatile
Temperature:     0.4
Max tokens:      800
Response format: json_object
Output:          { summary, keyPoints, funFact }
```

### `src/lib/video/types.ts`
**Purpose:** TypeScript interfaces for all video data.

```typescript
type SceneType = "TextScene" | "ComparisonScene" | "CodeScene" | "TerminalScene";

interface SceneData {
  type: SceneType;
  duration: number;   // milliseconds (all 6 scenes sum to 60,000)
  data: any;          // shape varies by scene type (see below)
}

interface VideoLesson {
  topic: string;
  script: string;     // 60-second narration text
  scenes: SceneData[];// exactly 6 items
  mcqs: any[];        // 3 MCQ objects
  notes: any;         // { summary, keyPoints, funFact }
}
```

**`data` payload shapes by scene type:**

```typescript
// TextScene
{ heading: string; body: string; color: string; /* hex */ }

// ComparisonScene
{ leftTitle: string; leftBody: string; rightTitle: string; rightBody: string; }

// CodeScene
{ code: string; language: string; description: string; }

// TerminalScene
{ lines: string[]; prompt: string; }
```

### `src/app/(dashboard)/practice/video/[topic]/page.tsx`
**Purpose:** The video player page. Fetches the lesson and renders the player.

**Key Logic:**
1. `useParams()` reads `topic` from the URL
2. On mount: `fetch('/api/practice/video/compile', { method: 'POST', body: JSON.stringify({ topic }) })`
3. Shows loading spinner while fetching (can take 5–15 sec)
4. On success: mounts `<InteractiveVideoPlayer lesson={lesson} />`
5. After video completes: "Take Quiz" button → `/practice/video/[topic]/mcq`

### `src/components/practice/video/InteractiveVideoPlayer.tsx`
**Purpose:** Core playback component. Syncs scenes with TTS narration.

**Key Logic:**

```
State:
  isPlaying         → bool, TTS active?
  currentSceneIdx   → int, which scene is shown
  progress          → 0–100%, video elapsed %
  isFinished        → bool

Refs:
  synthRef          → SpeechSynthesisUtterance instance
  startTimeRef      → performance.now() when play started
  animFrameRef      → requestAnimationFrame ID

On Play:
  1. Create SpeechSynthesisUtterance with lesson.script
  2. Voice priority: "Google US English" → "Samantha" → "Zira" → any en-US
  3. Start window.speechSynthesis.speak()
  4. Start requestAnimationFrame loop → animate()

animate() loop:
  elapsed = now - startTimeRef
  progress = (elapsed / totalDuration) * 100
  Scan through scenes accumulating time → set currentSceneIdx
  Runs until elapsed >= totalDuration
```

**UI Elements:**
- Dark header bar → topic title, "AI Generated" badge, slide count
- `aspect-video` viewport → renders current scene via `SceneRenderer`
- Initial play overlay → large play button + "Click to begin"
- Slide counter (top-right) → `{currentIdx + 1} / {total}` during playback
- Finished overlay → checkmark, "Lesson Complete!", total slides recap
- Controls bar → gradient progress bar, green play/pause button, restart, timer, slide dots

### `src/components/practice/video/SceneRenderer.tsx`
**Purpose:** Routes the current `SceneData` to the correct scene component.

```typescript
switch (scene.type) {
  case "TextScene"       → <TextScene data={scene.data} />
  case "ComparisonScene" → <ComparisonScene data={scene.data} />
  case "CodeScene"       → <CodeScene data={scene.data} />
  case "TerminalScene"   → <TerminalScene data={scene.data} />
}
```

### Scene Components (`src/components/practice/video/scenes/`)

#### `TextScene.tsx`
- Full-screen background with custom `hex` color from AI
- `text-7xl font-black` heading
- `text-4xl` body text

#### `ComparisonScene.tsx`

- Left: green accent (`#56C99A`), right: blue accent (`#6BA5F2`)

- Mac window chrome (red/yellow/green dots)
- Dark `#0D1117` background (GitHub-style)
- `pre > code` block in `text-2xl` monospace
- Language label in top-right corner

#### `TerminalScene.tsx`
- Black terminal window
- Lines revealed one-by-one via `setInterval` (800ms per line)
- Green `$` prompt prefix per line
- Blinking cursor while lines are still revealing
- `text-2xl` monospace

## ⏱️ Generation Time

| Step | Approx. Time |
|---|---|
| Script (sequential) | ~2–4 sec |
| Scenes + MCQs + Notes (parallel) | ~4–8 sec |
| **Total** | **~6–12 seconds** |

---

## 🎙️ TTS Voice Priority

The player tries voices in this order:
1. `Google US English`
2. `Samantha` (macOS)
3. `Zira` (Windows)
4. Any voice with `lang === "en-US"`

Voice availability depends on the user's browser and OS.
